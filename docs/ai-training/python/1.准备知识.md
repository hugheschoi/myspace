# 1. 准备知识

## 1.1 计算机组成

**冯·诺依曼体系结构**

- **存储**：数据以二进制形式存入存储器。
- **五大部件**：运算器、控制器、存储器、输入设备、输出设备。

**CPU**

- **控制器**：解析指令、协调各部件工作（角色类似项目经理）。
- **运算器**：算术运算（加减乘除）与逻辑运算（与、或、非、比较）。
- **性能**：主频（单核速度）+ 核心数（并行能力）。

**存储器（按速度由快到慢）**

- **CPU 内高速存储**（寄存器、缓存等）：极快、容量小，存放当前要执行的指令与数据。
- **内存（RAM）**：较快、容量相对小、断电易失；运行软件时，程序与数据主要在这里。
- **硬盘（外存）**：容量大、较慢；保存文件后可长期存放。

**输入 / 输出设备**：键盘、鼠标、显示器、打印机等，负责与人交互。

## 1.2 操作系统

操作系统负责在硬件之上**统一管理资源**，常见职能如下。

| 职能 | 要点 |
|------|------|
| **进程管理** | 进程 = 正在运行的程序实例；负责创建/结束、调度、同步与通信，让少量 CPU 核心高效支撑大量软件。 |
| **内存管理** | 分配与回收、内存保护（进程不能越界访问）、虚拟内存（用硬盘扩展“可用内存”）。 |
| **文件系统** | 组织磁盘上的文件与目录。 |
| **设备管理** | 设备驱动提供统一接口；缓冲与调度，隐藏硬件差异。 |
| **用户接口** | 命令行（CLI）、图形界面（GUI）。 |

### 1.2.1 启动过程（串联硬件与系统）

1. **通电**：按下电源。
2. **BIOS/UEFI 自检**：固件检查 CPU、内存、显卡等是否可用。
3. **引导加载**：按启动顺序（硬盘、U 盘等）找到引导程序，载入内存。
4. **加载内核**：引导程序从磁盘加载操作系统内核（核心管理模块）。
5. **初始化**：加载驱动，启动网络、声音、计划任务等系统服务。
6. **用户界面**：出现登录界面或桌面，等待用户操作。

## 1.4 编程语言

**本质**：人类想法 → **翻译** → 机器能执行的指令（机器码）。编程语言是人与计算机之间的桥梁。

**三个层次**

1. **机器语言**：0 和 1，CPU 直接执行；最快，人几乎无法直接编写维护。
2. **汇编语言**：用助记符（如 `ADD`、`MOV`）表示指令；仍贴近硬件，偏底层。
3. **高级语言**：接近自然语言（多为英语）与数学表达式，便于开发与维护。

**高级语言如何被执行**

| 方式 | 比喻 | 特点 | 常见语言 |
|------|------|------|----------|
| **编译** | 先整本译成书，再反复读 | 执行通常较快；可执行文件往往与平台相关 | C、C++、Go |
| **解释** | 同声传译，边译边执行 | 一般较慢；跨平台相对容易 | JavaScript、Python、PHP |
| **字节码 + 虚拟机** | 先编译成中间码，再由虚拟机执行 | 在速度与跨平台之间折中 | Java |
