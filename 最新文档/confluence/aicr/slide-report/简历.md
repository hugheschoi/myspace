**项目经验：IBS CLI - AI Code Review Shift-Left 命令行工具**

项目描述：  
参与设计并实现内部 AI Code Review 命令行工具 `@shopee/ibs-cli`，用于在开发阶段自动采集 Git 变更上下文、创建后端审查会话，并通过 Cursor Deep Link 触发 AI Code Review 工作流，实现代码审查前置化与本地研发流程集成。

技术栈：  
Node.js、CommonJS、Commander、Git Hooks、Shell、Cursor Deep Link、macOS URL Scheme、GitLab MR、REST API

职责与成果：

- 设计并实现 `ibs cr` 核心审查流程，支持暂存区审查、分支对比、Commit 对比、GitLab MR URL 审查和 rerun 复跑模式，覆盖多种开发提交流程。
- 封装 Git 数据采集能力，基于 `git diff --numstat --patch` 一次性获取文件变更统计与完整 patch，并结合远程过滤规则排除测试、mock、docs、删除文件等低价值内容，降低审查噪音和上传体积。
- 接入后端 CR Session API，将 workspace、用户信息、项目标识、分支信息、commit 列表、diff 文件、Cursor 自定义规则等上下文结构化上传，为服务端分批审查和重复检测提供数据基础。
- 实现 Cursor Deep Link 调用链路，将后端返回的 `session_id` 自动转换为 Cursor prompt，触发 `cr_shift_left_batch_review` 工具调用，减少用户手动复制粘贴和操作成本。
- 设计 Git Hooks 管理模块，支持全局 `pre-push`、`pre-commit`、`post-commit` 安装与卸载，并兼容本地 `.git/hooks`、Husky、自定义 `core.hooksPath` 等多种 hooks 配置方式。
- 实现本地 hook wrapper 机制，对已有 hook 自动备份、包装和恢复，保证 AI CR 逻辑接入的同时不破坏项目原有 lint、test、commit 校验流程。
- 增加 CI/CD 环境识别与跳过机制，避免 hooks 安装、卸载、注入逻辑影响流水线执行稳定性。
- 支持 macOS `ibs://` URL Scheme 注册，使浏览器或平台页面可通过链接直接唤起本地 CLI，实现审查任务从平台到本地 IDE 的闭环触发。
- 梳理项目风险点并提出优化方向，包括 diff 压缩一致性、shell 命令安全、全局 hooksPath 覆盖风险、生命周期脚本接线和自动化测试补齐等。

**IBS CLI - AI Code Review Shift-Left 工具**

- 基于 Node.js + Commander 开发内部 CLI 工具 `@shopee/ibs-cli`，用于采集 Git diff、创建后端 CR Session，并通过 Cursor Deep Link 自动触发 AI Code Review。

- 设计 Git Hooks 管理能力，支持全局 hooks、本地 hooks、Husky、自定义 hooksPath 场景，提供 hook 备份、包装、恢复和 CI 跳过机制。
