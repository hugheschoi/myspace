**项目名称：Transify 前端国际化翻译工具**

**项目描述：**  
Transify 是面向供应链前端业务的国际化翻译工具，用于统一生成翻译 Key、收集业务文案、对接翻译平台，并支持开发态调试和命令行自动化扫描上传。工具通过 `$gt` 翻译函数降低业务侧国际化接入成本，提升翻译 Key 管理的一致性和可维护性。

**技术栈：**  
TypeScript、Vue i18n、Rollup、MD5、Browser API、SessionStorage、CLI 工具链

**个人职责 / 项目贡献：**

- 设计并实现统一翻译 Key 生成规则，基于 `project + namespace + label` 生成 16 位 MD5 Key，解决手写 Key 不规范、命名冲突和维护成本高的问题。
- 封装 `generateTransifyVueI18n`，基于 vue-i18n 生成统一 `$gt` 翻译函数，支持默认文案、命名空间、插值参数和生产环境 fallback。
- 实现开发态翻译 Key 自动收集能力，在缺失翻译时将 `key -> label` 暂存到 `sessionStorage`，并提供控制台导出、清理等调试工具。
- 梳理翻译工具完整链路，包括 Key 生成、运行时翻译、开发态收集、JSON 导出、CLI 扫描上传、语言包下载等流程。
- 参与规范化国际化使用方式，明确 `$gt` 静态字符串、namespace、插值参数等最佳实践，降低翻译冲突和扫描遗漏风险。
- 输出项目技术文档，沉淀工具原理、API 说明、使用流程、CLI 命令和后续优化方向，便于团队接入和维护。

**项目成果：**

- 降低业务项目国际化接入复杂度，开发者只需编写默认文案即可生成规范翻译 Key。
- 提升翻译 Key 的一致性和可追踪性，减少手动维护 Key 带来的冲突和遗漏。
- 支持开发态自动收集缺失文案，提升翻译录入效率。
- 沉淀通用工具能力，可复用于多个前端业务项目。
